# Story 5.1 — Blocos de Secoes

## Descricao

Como usuario, quero copiar secoes completas prontas (hero, pricing, testimonials, etc.) pra montar landing pages rapidamente.

## Status: Pending

## Blocos (MVP ~10)

**Hero (3):**
1. Hero Centered — titulo grande, subtitulo, 2 CTAs, background gradient
2. Hero Split — texto esquerda, imagem/video direita
3. Hero Animated — texto animado + particles/grid background

**Social Proof (2):**
4. Testimonials Grid — cards testimonial em grid responsivo
5. Logos Carousel — logos clientes/parceiros em scroll infinito

**Pricing (2):**
6. Pricing Table — 3 planos, toggle mensal/anual, badge popular
7. Pricing Comparison — tabela feature comparison

**CTA (2):**
8. CTA Banner — faixa com countdown + CTA urgente
9. CTA Section — titulo + subtitulo + form email + social proof mini

**Footer (1):**
10. Footer Multi-Column — links, newsletter, social, copyright

## Criterios de Aceite

- [ ] 10 blocos implementados em `packages/registry/blocks/`
- [ ] Cada bloco: composicao de componentes base + FOMO
- [ ] Responsivo mobile-first
- [ ] Customizavel via props (textos, cores, imagens placeholder)
- [ ] Copy-paste friendly (bloco = 1 arquivo ou poucos)
- [ ] Previews no site (pagina dedicada /blocks)
- [ ] CLI: `npx wi-ui add block/hero-centered`

## Tarefas Tecnicas

1. Estrutura:
   ```
   packages/registry/blocks/hero-centered/
   ├── hero-centered.tsx
   ├── meta.json (category: block, deps: [button, animated-text])
   └── docs.mdx
   ```
2. Implementar cada bloco:
   - Composicao de componentes existentes
   - Props pra textos, imagens, links
   - Variantes onde aplicavel
3. Atualizar CLI pra suportar `add block/<name>`
4. Criar pagina `/blocks` no site:
   - Grid visual com preview de cada bloco
   - Filtro por categoria
   - Copy code button
5. Atualizar registry API pra servir blocos
6. Docs MDX com exemplos (bloco em contexto de landing page)
