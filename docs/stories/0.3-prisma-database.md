# Story 0.3 — Prisma + Database Setup

## Descricao

Como desenvolvedor, quero o banco de dados configurado com Prisma e schema base, para que features com persistencia possam ser desenvolvidas.

## Status: Pending

## Criterios de Aceite

- [ ] Prisma instalado e configurado
- [ ] Schema base criado (User, Session, Component, Theme)
- [ ] Conexao com PostgreSQL (Neon) funcionando
- [ ] Migration inicial rodada
- [ ] Prisma Client gerado
- [ ] Seed script basico criado
- [ ] PrismaClient singleton em `src/shared/infrastructure/`
- [ ] .env.example com DATABASE_URL documentado

## Tarefas Tecnicas

1. `pnpm add prisma @prisma/client`
2. `pnpm prisma init`
3. Criar schema com models:
   - User (id, name, email, image, createdAt, updatedAt)
   - Session (id, userId, token, expiresAt)
   - Component (id, name, slug, category, description, code, deps, createdAt)
   - Theme (id, name, colors, userId, isPublic, createdAt)
4. Configurar datasource (postgresql, env DATABASE_URL)
5. Criar `src/shared/infrastructure/database/prisma-client.ts` (singleton)
6. Criar `prisma/seed.ts` com dados mock
7. Configurar scripts no package.json (db:push, db:seed, db:studio)
8. Criar .env.example
9. Rodar migration inicial
10. Testar conexao

## Dependencias

- Story 0.2 (estrutura DDD precisa existir)

## Notas

- Usar Neon (PostgreSQL serverless) como DB
- Prisma schema pode evoluir — migration strategy: `prisma db push` em dev, `prisma migrate` em prod
