# Story 0.2 — Estrutura DDD + Monorepo

## Descricao

Como desenvolvedor, quero a estrutura de pastas DDD modular e base do monorepo configurada, para que features sejam desenvolvidas em bounded contexts isolados.

## Status: Pending

## Criterios de Aceite

- [ ] Estrutura `src/features/` criada com todos bounded contexts
- [ ] Estrutura `src/shared/` (domain, infrastructure, ui)
- [ ] Estrutura `src/lib/` (utils, helpers)
- [ ] `packages/cli/` inicializado com citty
- [ ] `packages/registry/` inicializado
- [ ] Path aliases `@/` configurados no tsconfig
- [ ] Turborepo configurado (turbo.json)
- [ ] pnpm workspaces configurado (pnpm-workspace.yaml)
- [ ] Build passa sem erros

## Tarefas Tecnicas

1. Criar estrutura `src/features/` com subpastas:
   - `auth/` (domain, application, infrastructure, presentation)
   - `components/` (domain, application, infrastructure, presentation)
   - `registry/` (domain, application, infrastructure, presentation)
   - `themes/` (domain, application, infrastructure, presentation)
   - `playground/` (domain, application, presentation)
2. Criar `src/shared/domain/`, `src/shared/infrastructure/`, `src/shared/ui/`
3. Criar `src/lib/`
4. Inicializar `packages/cli/` com package.json + citty
5. Inicializar `packages/registry/` com package.json
6. Criar `pnpm-workspace.yaml` com packages/*
7. Instalar e configurar Turborepo (turbo.json com pipelines)
8. Ajustar tsconfig.json com path aliases (@/features/*, @/shared/*, @/lib/*)
9. Adicionar .gitkeep nos diretorios vazios
10. Validar build funciona
