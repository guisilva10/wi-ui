## Tarefas Tecnicas

1. Audit acessibilidade:
   - Rodar axe-core em todos componentes
   - Fix issues level A e AA
   - Testar navegacao teclado
2. Performance audit:
   - Lighthouse CI
   - Bundle analysis (next-bundle-analyzer)
   - Otimizar imports, lazy load
3. Configurar Changesets:
   - `pnpm add @changesets/cli`
   - `pnpm changeset init`
   - Configurar GitHub Action pra release
4. Preparar repo:
   - README com badges, install, quick start
   - CONTRIBUTING guide
   - Issue templates
   - PR template
5. Dominio + DNS (wi-ui.dev)
6. Analytics (Plausible ou Vercel Analytics)
7. Error tracking (Sentry)
8. Marketing assets (og:image, screenshots, GIFs)
