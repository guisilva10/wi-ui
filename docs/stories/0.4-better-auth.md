# Story 0.4 — Better Auth Setup

## Descricao

Como usuario, quero poder criar conta e fazer login no site WI.UI, para acessar dashboard, salvar temas e favoritar componentes.

## Status: Pending

## Criterios de Aceite

- [ ] Better Auth instalado e configurado
- [ ] Providers: email/password + GitHub OAuth
- [ ] Middleware de protecao de rotas autenticadas
- [ ] Feature `auth/` implementada (domain → presentation)
- [ ] Paginas: /login, /register, /forgot-password
- [ ] Session management funcionando
- [ ] Redirect apos login pra /dashboard
- [ ] Logout funcional
- [ ] Auth context/hook disponivel (`useSession`)

## Tarefas Tecnicas

1. `pnpm add better-auth`
2. Configurar Better Auth (`src/lib/auth.ts`):
   - Database adapter (Prisma)
   - Email/password provider
   - GitHub OAuth provider
3. Criar API route `/api/auth/[...all]`
4. Implementar feature `auth/`:
   - domain: User entity, Session VO, AuthRepository interface
   - application: LoginUseCase, RegisterUseCase, LogoutUseCase
   - infrastructure: BetterAuthAdapter
   - presentation: LoginForm, RegisterForm, useSession hook
5. Criar paginas:
   - `src/app/(auth)/login/page.tsx`
   - `src/app/(auth)/register/page.tsx`
6. Criar middleware.ts (proteger /dashboard/*)
7. Configurar env vars (BETTER_AUTH_SECRET, GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET)
8. Atualizar .env.example
9. Testar fluxo completo login/register/logout

## Dependencias

- Story 0.3 (Prisma precisa estar configurado)
