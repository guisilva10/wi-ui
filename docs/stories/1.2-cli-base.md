# Story 1.2 — CLI Base (@wi-ui/cli)

## Descricao

Como dev usuario, quero instalar e usar CLI pra adicionar componentes WI.UI no meu projeto sem copiar manualmente.

## Status: Pending

## Comandos MVP

- `npx wi-ui init` — detecta projeto, configura tailwind paths, cria wi-ui.json
- `npx wi-ui add <component>` — fetch registry, resolve deps, copia arquivos
- `npx wi-ui list` — lista componentes disponiveis

## Criterios de Aceite

- [ ] Package `@wi-ui/cli` publicavel
- [ ] `init` detecta projeto Next/React, cria config
- [ ] `add` baixa componente do registry e copia pro projeto
- [ ] `add` resolve dependencias entre componentes automaticamente
- [ ] `list` mostra componentes disponiveis com categorias
- [ ] Arquivo config `wi-ui.json` na raiz do projeto usuario
- [ ] Funciona com pnpm, npm, yarn, bun
- [ ] Error handling claro (componente nao existe, rede falhou, etc.)

## Tarefas Tecnicas

1. Setup package `packages/cli/`:
   - package.json com bin entry
   - citty como framework CLI
   - TypeScript + tsup (build)
2. Implementar comando `init`:
   - Detectar framework (next.config, vite.config)
   - Detectar tailwind
   - Criar `wi-ui.json` (componentsDir, tailwindConfig, aliases)
   - Instalar deps necessarias (tailwind-merge, clsx)
3. Implementar comando `add`:
   - Ler wi-ui.json
   - Fetch componente do registry API
   - Resolver deps (se Button precisa cn(), instalar cn primeiro)
   - Copiar arquivos pro diretorio configurado
   - Atualizar index exports
4. Implementar comando `list`:
   - Fetch registry API /api/registry/list
   - Display formatado por categoria
5. Testes e2e (simular projeto, rodar comandos)

## Dependencias

- Story 0.2 (packages/cli existe)
- Story 1.1 (precisa componentes no registry pra testar)

## Notas

- citty escolhido: TS nativo, 5KB, DX simples
- Registry API URL configuravel (default: wi-ui.dev/api/registry)
