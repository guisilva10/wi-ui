# Story 2.2 — Componentes Animacao

## Descricao

Como usuario da lib, quero componentes com animacoes modernas e performaticas, para dar vida as interfaces sem precisar configurar Framer Motion do zero.

## Status: Pending

## Componentes (5)

1. **Animated Text** — typewriter, fade-in word-by-word, gradient shift, scramble
2. **Scroll Reveal** — fade up/down/left/right ao entrar viewport, stagger children
3. **Magnetic Button** — segue cursor com spring, efeito magnetico hover
4. **Gradient Border** — borda animada com gradiente rotacionando, glow effect
5. **Number Ticker** — contagem animada de 0 ate N, formatacao (currency, %, separadores)

## Criterios de Aceite

- [ ] 5 componentes implementados em `packages/registry/animation/`
- [ ] motion (mini Framer Motion) como dep opcional
- [ ] CSS-only fallback quando possivel
- [ ] Respeita `prefers-reduced-motion`
- [ ] Performance: 60fps, no layout thrashing
- [ ] Configuravel (duration, delay, easing, variants)
- [ ] Metadata + docs MDX
- [ ] Testes basicos

## Tarefas Tecnicas

1. Estrutura:
   ```
   packages/registry/animation/animated-text/
   ├── animated-text.tsx
   ├── variants/ (typewriter.ts, fade-words.ts, scramble.ts)
   ├── meta.json
   └── docs.mdx
   ```
2. Implementar cada componente:
   - Animated Text: variants pattern, IntersectionObserver trigger
   - Scroll Reveal: IO hook, stagger delay calc, threshold config
   - Magnetic Button: mouse position tracking, spring physics
   - Gradient Border: conic-gradient rotation, CSS custom properties
   - Number Ticker: requestAnimationFrame, easing functions, Intl.NumberFormat
3. Criar hook `useIntersectionObserver` em shared
4. Criar hook `useMousePosition` em shared
5. Implementar `prefers-reduced-motion` check global
6. Testes (render, animations trigger, reduced motion)
7. Docs com demos visuais

## Dependencias

- Story 0.2 (estrutura)
- Story 1.3 (registry pra servir)

## Notas

- motion (18KB) so quando CSS puro nao resolve (spring physics, complex sequences)
- Inspiracao: magic-ui, react-bits, aceternity
- Cada componente deve ter versao CSS-only e versao motion-enhanced
