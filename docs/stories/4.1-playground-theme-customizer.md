# Story 4.1 — Playground / Theme Customizer

## Descricao

Como usuario, quero customizar visualmente cores, tipografia e espacamento dos componentes em tempo real, para gerar tema personalizado e exportar pro meu projeto.

## Status: Pending

## Funcionalidades

- Editor visual de tema (color pickers, sliders, toggles)
- Preview ao vivo de componentes com tema aplicado
- Presets de temas prontos (dark, neon, minimal, corporate, etc.)
- Export: CSS vars, tailwind config, wi-ui theme file
- Salvar temas (requer login)
- Compartilhar tema via URL

## Criterios de Aceite

- [ ] Feature `playground/` implementada
- [ ] Editor com controles visuais (cores, radius, spacing, font)
- [ ] Preview renderiza componentes reais com tema
- [ ] Presets de tema (minimo 5)
- [ ] Export gera codigo correto (CSS vars + Tailwind)
- [ ] Salvar tema no DB (autenticado)
- [ ] Share URL funciona (tema serializado na URL)
- [ ] Responsivo (editor collapsa mobile)
- [ ] Performance OK (sem lag no preview)

## Tarefas Tecnicas

1. Implementar feature `themes/`:
   - domain: Theme entity, ColorScheme VO, ThemeRepository
   - application: CreateThemeUseCase, ListThemesUseCase, ExportThemeUseCase
   - infrastructure: PrismaThemeRepository, CSSVarsGenerator
2. Implementar feature `playground/`:
   - presentation: PlaygroundEditor, LivePreview, ControlPanel, ExportModal
3. Criar pagina `/playground`:
   - Layout split: controls (left) + preview (right)
   - Mobile: tabs (controls / preview)
4. Implementar controles:
   - Color pickers (primary, secondary, accent, background, foreground)
   - Border radius slider (0-24px)
   - Spacing scale
   - Font family selector
   - Dark/light toggle
5. Implementar preview:
   - Render componentes reais com CSS vars dinamicas
   - Showcase: buttons, cards, inputs, badges, dialog
6. Implementar presets:
   - 5+ temas pre-definidos
   - Apply preset = preenche controles
7. Implementar export:
   - Gerar `:root { --primary: ... }` CSS
   - Gerar @theme Tailwind v4 config
   - Gerar wi-ui.json theme section
8. Salvar tema (API route + Prisma)
9. Share URL (tema comprimido em query params)

## Dependencias

- Story 0.4 (auth pra salvar temas)
- Story 1.1, 2.1, 2.2 (componentes pra preview)

## Notas

- Inspiracao: tweakcn.com, realtime-colors.com, shadcn themes
- CSS vars (@theme Tailwind v4) = customizacao sem rebuild
- Temas compartilhados podem virar galeria publica futuramente
